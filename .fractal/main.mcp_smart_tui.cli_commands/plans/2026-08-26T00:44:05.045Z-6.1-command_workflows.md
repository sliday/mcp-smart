Deliver pure `init`, `doctor`, and `ask` functions in `src/commands/` plus
focused command tests. No child delegation is possible: this node is a leaf
(`max_depth`, `max_children`, and `max_descendants` are all zero).

1. Record the verified preflight for `contracts.ts`, `openrouter.ts`, the CLI
   boundary, and current tests in node memory before changing the test file.
2. Add the smallest command test for one behavior at a time and run the focused
   Vitest command to capture its expected RED result.
3. Add only the production code needed for that behavior, then rerun the same
   command for GREEN. Cover setup guidance, doctor’s missing-key/no-probe path,
   JSON-safe error data, empty task validation, client delegation, and exact
   multiline task preservation without provider calls.
4. Run the focused command tests, adjacent CLI/routing tests, TypeScript build,
   the inherited test script, and `git diff --check`.
5. Fold exact TDD evidence into memory, report the delivered interface and
   verification to the outbox, commit only owned project files, and finish the
   node if all gates pass.
